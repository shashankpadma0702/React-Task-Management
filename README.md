# React Task Management System

A role-based task management application built with React, featuring drag-and-drop functionality and local storage persistence.

## Features

- **Role-Based Access Control**
  - Admin: Create, assign, and reassign tasks
  - User: View assigned tasks and update status
- **Drag & Drop Reassignment**: Admin can drag tasks and drop on users to reassign
- **Local Storage**: All data persists in browser storage
- **Responsive Design**: Works on desktop and mobile devices
